# 总控对话与独立会话实施计划

目标是让用户在总控看到实际执行者、发给它的指令和结果。每个新任务独立创建原生会话，补充内容续接原任务。沿用 SQLite、Runtime、Codex 原生适配器和 React 桌面端。设计见 ../specs/2026-11-04-supervisor-conversation-design.md。

- 路由与派发。model.ts 提取直接提问，runtime.ts 依据已保存的执行者和目标生成回执。用多个任务、相同问题分给不同执行者及目录排队用例核对。
- 信息补充。runtime.ts 区分输入和授权，核查同一任务中用户明确提供的事实并记录送达。用已知地点、未知地点、重复问题和原生会话续接验证。
- 总控呈现。renderer.tsx 显示简短回执、必要追问和结果，完整信息放入详情。用并行归属、外部会话、历史消息和人工审批验证。
- 完成反馈。纯问答直接展示执行者返回的公开答案。需要检查的工作继续使用现有状态与交付检查。通过隔离测试、类型检查和构建后写回源码。
